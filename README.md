# URL Shortening Service

## url-shortening-service

This is a simple [RESTful API](https://roadmap.sh/projects/url-shortening-service) that allows users to shorten long URLs. The API provides endpoints to create, retrieve, update, and delete short URLs. It also provides statistics on the number of times a short URL has been accessed.
